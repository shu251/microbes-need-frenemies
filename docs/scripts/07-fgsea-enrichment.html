Ranked list: vent vs. non-vent contrast for each vent-associated KO

Ranking statistic = Cliff’s delta between vent and non-vent sample units for each KO’s robust-CLR values (contrast_ranks(), R/cliffs_delta.R). Positive delta means that KO ranks higher at vents; the magnitude is the net share of vent/non-vent unit pairs agreeing on the direction (Cliff 1993, Psychol Bull 114:494-509; Vargha and Delaney 2000, J Educ Behav Stat 25:101-132).

This reverses the note that a vent-vs-non-vent contrast must not enter through fgsea (that note dated 2026-09-25; reversed 2026-09-27). The reason the differential was dropped is specific to the KO-level test: with 13 vent and 6 non-vent units, no permutation p reaches BH significance and the differential set empties. fgsea never tests a KO on its own, it asks whether a whole gene set sits toward one end of the ranked list, which is the case GSEA was built for (Subramanian et al. 2005, PNAS 102:15545-15550). The set-level result is a different test at a different resolution, not a re-entry of the dropped one, and it does not depend on any single KO clearing max-T. Keep saying relative: this is compositional.

The universe is the vent-associated KO set (detected in >= 30% of vent units, i.e. >= 4 of 13, under the shared detection rule; 05), read from 06’s span table rather than recomputed, so the ranked list and the gene sets below describe exactly the same KOs. Units on both sides of the contrast come from the full paired table (vent + non-vent), since a vent-only matrix cannot express the contrast.

Sign check

A positive delta has to mean higher at vents. Check it against the CLR means of the two extreme KOs rather than trusting the convention, since an inverted sign would flip every NES in the table with no other symptom.

Code 
sign_check <- ranks_df |>
  slice(c(1, n())) |>
  mutate(mean_clr_vent    = map_dbl(ko_id, \(k) mean(ko_habitat_z[unit_is_vent, k])),
         mean_clr_nonvent = map_dbl(ko_id, \(k) mean(ko_habitat_z[!unit_is_vent, k])),
         agrees           = sign(delta_vent) == sign(mean_clr_vent - mean_clr_nonvent))

Heterotrophy categories and subcategories

Read from data/gene-lists/het_gene_reference.csv, the panel compiled by scripts/00_build_het_gene_reference.R. That script — not this document — resolves the awkward KEGG fields in the source lists ("K04624-K08424 (family range)", "K21348 (representative)", "Not in KEGG KO (non-orthologous)", ;-separated lists) and logs every unresolvable row to output-tables/00_het_gene_reference_unresolved.csv.

On the family-range rows ("K04624-K08424 (family range)"): the builder keeps both boundary ids as members and does not expand the range. KEGG ortholog numbers are assigned roughly sequentially rather than by family, so K04624–K08424 spans ~3,800 unrelated orthologs; expanding it would inject thousands of KOs with nothing to do with this gene set. Real family membership needs an actual KEGG lookup (the ko entry in the KEGG API), and the unresolved log records the range so that can be done deliberately.

Category and pathway assignment in the curated lists is still partial, so sets are kept down to MIN_SET_SIZE = 5 rather than the usual 15. Re-run scripts/00_build_het_gene_reference.R and then this document as that membership grows.

KEGG level-C pathways and Burns et al. 2018 trophic-mode families

Two outside sources, so the result does not depend on hand-picked membership (2026-10-21: approaches A and B).

  • kegg_level_c: every KEGG pathway map in Transport and catabolism, Signal transduction, Cell growth and death and Cell motility, with full KEGG membership. Prokaryote-only maps (two-component system, bacterial chemotaxis, bacterial flagellar assembly, Caulobacter cell cycle) are dropped in 00b. Many signaling maps share the same kinase core, so these sets overlap; read them as one family, not as independent results.
  • burns2018: protein families whose presence predicts phagocytosis, photosynthesis or prototrophy across 35 eukaryotic genomes (Burns et al. 2018, Nat Ecol Evol 2:697–704), mapped from UniProt representatives to KOs in 00b. Those families were chosen to predict gene content; here they are tested for a shift in expression between habitats, which is a different question from the one they were built for.

The protist experimental set (00b) is too small to clear MIN_SET_SIZE in this universe; 06b reports it KO by KO instead.

Combine, tag by source

Size filtering happens on membership inside the ranked universe, not on raw membership. fgsea()’s own minSize applies to each set after intersecting it with stats, so a set with >= MIN_SET_SIZE KOs overall but fewer than that among the ranked KOs used to clear the filter here and then get dropped silently by fgsea(), which is what broke nrow(enrich) == length(all_sets) in the QC block (diagnosed and fixed 2026-09-27). Only the 06 class sets were ever immune, being built from ranks_df itself; the het and KEGG sets come from het_gene_reference.csv, which is not restricted to vent-associated KOs.

Multiple testing by family (>SKH: 2026-10-22). BH is applied within each family, not across every set: the original ten (span classes + curated heterotrophy subcategories + curated KEGG pathways) stay one family, as decided 2026-10-10, so adding the outside sources does not change their adjusted p-values. kegg_level_c and burns2018 are one family each.

fgsea

Set-level enrichment (GSEA), not a per-KO differential expression test. fgsea() takes the gene sets (all_sets) and the ranked statistic (ranks, Cliff’s delta vent vs. non-vent) and asks whether each set sits toward one end of the ranked list.

Code 
# BiocManager::install("fgsea")
library(fgsea)
set.seed(params$seed)
# ?fgsea()
enrich <- fgsea(pathways = all_sets, stats = ranks, minSize = MIN_SET_SIZE, eps = 0) |>
  as_tibble() |>
  mutate(source = set_source[pathway],
         family = unname(set_family[source])) |>
  relocate(source, family, .after = pathway) |>
  # >SKH: fgsea's padj is BH across every set passed in; recompute it within family
  mutate(padj = p.adjust(pval, method = "BH"), .by = family) |>
  # A 5-KO set gives an unstable NES and a 2-3 gene leading edge. Flagged rather
  # than dropped, so set size travels with every claim (2026-09-27).
  mutate(small_set = size < 10) |>
  arrange(padj)

Code 
enrich |> select(pathway, source, family, size, small_set, NES, pval, padj)
  • Pathway: tested gene set we looked at
  • source: where did gene set come from.
  • size: number of KOs in the gene set after filtering the ranked list
  • NES: normalized enrichment score. neg vs. pos is the direction of the enrichment (i.e., when positive it means they are positively enriched) and the magnitude is the strenth relative to the gene-set size
  • pval: permutation p-value
  • padj: BH-adjusted p-value

With the vent-vs-non-vent ranking, a positive NES means the set sits toward the vent-skewed (high-delta) end of the ranked list; negative means the non-vent-skewed end.

source: span_rank means the four 06 span classes (class-, phylum-, supergroup-restricted, cross-supergroup): is the vent-skewed signal carried by narrow or widely shared KOs?

Het_subcategory means that is includes the kegg pathways or het subcategory from curated gene list. This helps us understand which functional module is represented in the set looked at.

small_set flags sets holding fewer than 10 KOs of the ranked universe. MIN_SET_SIZE is 5 because panel membership is still partial, below the usual GSEA floor of 10-15, so report size alongside any claim from a flagged set.

Carrier control

A KO carried by one lineage moves with that lineage: if the lineage is a larger share at vents, the KO ranks toward the vent end whatever its function. This check removes that part. Each taxon’s vent-vs-non-vent Cliff’s delta is computed on the curated grain-4 taxon matrix exactly as for KOs; each KO’s delta is regressed on the delta of its top carrier taxon (from 06), and fgsea is re-run on the residuals for the span sets. A span class that stays enriched after the control is vent-skewed beyond its carriers’ turnover.

Sensitivity: order of tied ranks

Cliff’s delta between 13 vent and 6 non-vent units can only take values in steps of 1/78 (157 possible values), so many of the ranked KOs share a value and fgsea() warns that the order of tied KOs is arbitrary. Enrichment scores depend on that order. This check re-runs fgsea N_TIE_DRAWS times, each time adding jitter smaller than one third of the smallest gap between distinct values: the order within ties changes, the order between distinct values never does. The same check is applied to the carrier-control residuals. A set whose NES sign and BH call hold across draws does not depend on tie order.

SKH: assistant-added (2026-10-14).

Code 
N_TIE_DRAWS <- 100

tie_draws <- function(stats, sets, n_draws = N_TIE_DRAWS) {
  gap <- min(diff(sort(unique(stats))))
  if (!is.finite(gap)) gap <- 1e-6
  purrr::map_dfr(seq_len(n_draws), \(i) {
    jittered <- stats + stats::runif(length(stats), -gap / 3, gap / 3)
    fgsea(pathways = sets, stats = jittered, minSize = MIN_SET_SIZE, eps = 0) |>
      as_tibble() |>
      # >SKH: same within-family BH as the main run (span-only residual runs are one family)
      mutate(family = unname(set_family[set_source[pathway]]) |> replace_na("span_rank")) |>
      mutate(padj = p.adjust(pval, method = "BH"), .by = family) |>
      select(pathway, NES, padj) |>
      mutate(draw = i)
  })
}

summarise_ties <- function(draws) {
  draws |>
    summarise(NES_median  = median(NES, na.rm = TRUE),
              NES_min     = min(NES, na.rm = TRUE),
              NES_max     = max(NES, na.rm = TRUE),
              padj_median = median(padj, na.rm = TRUE),
              padj_max    = max(padj, na.rm = TRUE),
              frac_sig    = mean(padj <= params$fdr_alpha, na.rm = TRUE),
              sign_stable = all(sign(NES) == sign(median(NES, na.rm = TRUE)), na.rm = TRUE),
              .by = pathway)
}

message(glue("Tied values: {round(100 * mean(duplicated(ranks) | duplicated(ranks, fromLast = TRUE)), 1)}% ",
             "of the main ranking, {round(100 * mean(duplicated(ranks_resid) | duplicated(ranks_resid, fromLast = TRUE)), 1)}% ",
             "of the carrier-control residuals"))

set.seed(params$seed)
tie_sensitivity <- bind_rows(
  tie_draws(ranks, all_sets) |>
    summarise_ties() |>
    left_join(enrich |> select(pathway, source, size, NES, padj), by = "pathway") |>
    mutate(ranking = "vent vs. non-vent delta", .before = 1),
  tie_draws(ranks_resid, span_sets_resid) |>
    summarise_ties() |>
    left_join(enrich_control |> select(pathway, size, NES = NES_resid, padj = padj_resid),
              by = "pathway") |>
    mutate(ranking = "carrier-control residual", source = "span_rank", .before = 1)) |>
  arrange(ranking, padj)

# Ranked list: vent vs. non-vent contrast for each vent-associated KO

Ranking statistic = **Cliff's delta between vent and non-vent sample units** for
each KO's robust-CLR values (`contrast_ranks()`, `R/cliffs_delta.R`). Positive
delta means that KO ranks higher at vents; the magnitude is the net share of
vent/non-vent unit pairs agreeing on the direction (Cliff 1993, Psychol Bull
114:494-509; Vargha and Delaney 2000, J Educ Behav Stat 25:101-132).

**This reverses the note that a vent-vs-non-vent contrast must not enter through
fgsea** (that note dated 2026-09-25; reversed 2026-09-27). The reason the
differential was dropped is specific to the *KO-level* test: with 13 vent and 6
non-vent units, no permutation p reaches BH significance and the differential
set empties. fgsea never tests a KO on its own, it asks whether a whole gene set
sits toward one end of the ranked list, which is the case GSEA was built for
(Subramanian et al. 2005, PNAS 102:15545-15550). The set-level result is a
different test at a different resolution, not a re-entry of the dropped one, and
it does not depend on any single KO clearing max-T. Keep saying *relative*: this
is compositional.

The universe is the vent-associated KO set (detected in >= 30% of vent units,
i.e. >= 4 of 13, under the shared detection rule; 05), read from 06's span
table rather than recomputed, so the ranked list and the gene sets below
describe exactly the same KOs. Units on
**both** sides of the contrast come from the full paired table (vent +
non-vent), since a vent-only matrix cannot express the contrast.

## Sign check

A positive delta has to mean higher at vents. Check it against the CLR means of
the two extreme KOs rather than trusting the convention, since an inverted sign
would flip every NES in the table with no other symptom.

```{r delta-sign-check}
sign_check <- ranks_df |>
  slice(c(1, n())) |>
  mutate(mean_clr_vent    = map_dbl(ko_id, \(k) mean(ko_habitat_z[unit_is_vent, k])),
         mean_clr_nonvent = map_dbl(ko_id, \(k) mean(ko_habitat_z[!unit_is_vent, k])),
         agrees           = sign(delta_vent) == sign(mean_clr_vent - mean_clr_nonvent))

sign_check

stopifnot(all(sign_check$agrees))
```

## Combine, tag by source

# fgsea

Set-level enrichment (GSEA), not a per-KO differential expression test. `fgsea()` takes the gene sets (`all_sets`) and the ranked statistic (`ranks`, Cliff's delta vent vs. non-vent) and asks whether each set sits toward one end of the ranked list.

```{r fgsea, message=FALSE}
# BiocManager::install("fgsea")
library(fgsea)
set.seed(params$seed)
# ?fgsea()
enrich <- fgsea(pathways = all_sets, stats = ranks, minSize = MIN_SET_SIZE, eps = 0) |>
  as_tibble() |>
  mutate(source = set_source[pathway],
         family = unname(set_family[source])) |>
  relocate(source, family, .after = pathway) |>
  # >SKH: fgsea's padj is BH across every set passed in; recompute it within family
  mutate(padj = p.adjust(pval, method = "BH"), .by = family) |>
  # A 5-KO set gives an unstable NES and a 2-3 gene leading edge. Flagged rather
  # than dropped, so set size travels with every claim (2026-09-27).
  mutate(small_set = size < 10) |>
  arrange(padj)

enrich |> select(pathway, source, family, size, small_set, NES, pval, padj)
```


* Pathway: tested gene set we looked at
* source: where did gene set come from. 
* size: number of KOs in the gene set after filtering the ranked list
* NES: normalized enrichment score. neg vs. pos is the direction of the enrichment (i.e., when positive it means they are positively enriched) and the magnitude is the strenth relative to the gene-set size
* pval: permutation p-value
* padj: BH-adjusted p-value


With the vent-vs-non-vent ranking, a positive NES means the set sits toward
the vent-skewed (high-delta) end of the ranked list; negative means the
non-vent-skewed end.

*source*:
_span_rank_ means the four 06 span classes (class-, phylum-, supergroup-restricted, cross-supergroup): is the vent-skewed signal carried by narrow or widely shared KOs? 

_Het_subcategory_ means that is includes the kegg pathways or het subcategory from curated gene list. This helps us understand which functional module is represented in the set looked at. 

_small_set_ flags sets holding fewer than 10 KOs of the ranked universe.
`MIN_SET_SIZE` is 5 because panel membership is still partial, below the usual
GSEA floor of 10-15, so report size alongside any claim from a flagged set.

# Carrier control

A KO carried by one lineage moves with that lineage: if the lineage is a larger share at
vents, the KO ranks toward the vent end whatever its function. This check removes that
part. Each taxon's vent-vs-non-vent Cliff's delta is computed on the curated grain-4 taxon
matrix exactly as for KOs; each KO's delta is regressed on the delta of its top carrier
taxon (from 06), and fgsea is re-run on the residuals for the span sets. A span class
that stays enriched after the control is vent-skewed beyond its carriers' turnover.

>SKH:

```{r carrier-control}

                              id_col = "sample_id", aggregate = "mean", unit_col = "sample_unit")
taxon_delta <- tibble(top_carrier_L4 = colnames(taxon_habitat$z),
                      delta_carrier  = contrast_ranks(taxon_habitat$z, habitat_by_unit,
                                                      focal = "Vent"))

control_df <- ranks_df |>
  inner_join(taxon_delta, by = "top_carrier_L4") |>
  filter(is.finite(delta_carrier))
carrier_fit <- lm(delta_vent ~ delta_carrier, data = control_df)
control_df$delta_resid <- residuals(carrier_fit)

message(glue("KO delta ~ top-carrier delta: R2 = {round(summary(carrier_fit)$r.squared, 3)} ",
             "over {nrow(control_df)} KOs with a carrier"))

ranks_resid <- control_df |> arrange(desc(delta_resid)) |> select(ko_id, delta_resid) |> deframe()

  (\(x) x[lengths(x) >= MIN_SET_SIZE])()

                        minSize = MIN_SET_SIZE, eps = 0) |>
  as_tibble() |>
  select(pathway, size, NES_resid = NES, padj_resid = padj) |>
  left_join(enrich |> select(pathway, NES, padj), by = "pathway")
```

# Sensitivity: order of tied ranks

Cliff's delta between 13 vent and 6 non-vent units can only take values in steps of 1/78
(157 possible values), so many of the ranked KOs share a value and `fgsea()` warns that the
order of tied KOs is arbitrary. Enrichment scores depend on that order. This check re-runs
fgsea `N_TIE_DRAWS` times, each time adding jitter smaller than one third of the smallest
gap between distinct values: the order **within** ties changes, the order **between**
distinct values never does. The same check is applied to the carrier-control residuals.
A set whose NES sign and BH call hold across draws does not depend on tie order.

>SKH: assistant-added (2026-10-14).

```{r tie-sensitivity}
#| message: true
#| warning: false
N_TIE_DRAWS <- 100

tie_draws <- function(stats, sets, n_draws = N_TIE_DRAWS) {
  gap <- min(diff(sort(unique(stats))))
  if (!is.finite(gap)) gap <- 1e-6
  purrr::map_dfr(seq_len(n_draws), \(i) {
    jittered <- stats + stats::runif(length(stats), -gap / 3, gap / 3)
    fgsea(pathways = sets, stats = jittered, minSize = MIN_SET_SIZE, eps = 0) |>
      as_tibble() |>
      # >SKH: same within-family BH as the main run (span-only residual runs are one family)
      mutate(family = unname(set_family[set_source[pathway]]) |> replace_na("span_rank")) |>
      mutate(padj = p.adjust(pval, method = "BH"), .by = family) |>
      select(pathway, NES, padj) |>
      mutate(draw = i)
  })
}

summarise_ties <- function(draws) {
  draws |>
    summarise(NES_median  = median(NES, na.rm = TRUE),
              NES_min     = min(NES, na.rm = TRUE),
              NES_max     = max(NES, na.rm = TRUE),
              padj_median = median(padj, na.rm = TRUE),
              padj_max    = max(padj, na.rm = TRUE),
              frac_sig    = mean(padj <= params$fdr_alpha, na.rm = TRUE),
              sign_stable = all(sign(NES) == sign(median(NES, na.rm = TRUE)), na.rm = TRUE),
              .by = pathway)
}

message(glue("Tied values: {round(100 * mean(duplicated(ranks) | duplicated(ranks, fromLast = TRUE)), 1)}% ",
             "of the main ranking, {round(100 * mean(duplicated(ranks_resid) | duplicated(ranks_resid, fromLast = TRUE)), 1)}% ",
             "of the carrier-control residuals"))

set.seed(params$seed)
tie_sensitivity <- bind_rows(
  tie_draws(ranks, all_sets) |>
    summarise_ties() |>
    left_join(enrich |> select(pathway, source, size, NES, padj), by = "pathway") |>
    mutate(ranking = "vent vs. non-vent delta", .before = 1),
  tie_draws(ranks_resid, span_sets_resid) |>
    summarise_ties() |>
    left_join(enrich_control |> select(pathway, size, NES = NES_resid, padj = padj_resid),
              by = "pathway") |>
    mutate(ranking = "carrier-control residual", source = "span_rank", .before = 1)) |>
  arrange(ranking, padj)

tie_sensitivity |>
  mutate(across(where(is.double), \(x) signif(x, 3)))
```
